# Kode_core_desktop_app
Koda Core — десктопный AI-ассистент с локальной нейросетью (Qwen 2.5 3B/7B), агентной системой и полной конфиденциальностью. Работает офлайн: читает PDF, DOCX, XLSX, изображения (OCR), создаёт документы, таблицы, код и архивы. Поддерживает веб-поиск, стриминг ответов, голосовой ввод и 5 типов AI-агентов.
